# Подготовка компоновки этапа 3

Дата: 16 ноября 2026 года. Продолжение PR №4 после этапа 2.

## Подготовлено в коде

- AI-помощник свёрнут по умолчанию в строку высотой 36 px, рядом размещены быстрые ответы. Панель открывается поверх переписки по клику или Alt+A, закрывается повторным кликом, Esc, кликом вне панели, после отправки или отклонения. Длинное содержимое панели прокручивается отдельно.
- В строке помощника отображаются состояние и начало текущего черновика. Повторяющиеся предупреждения объединены. Вместо JSON инструментов показаны пояснения; исходные данные раскрываются только у администратора.
- Быстрые ответы открываются во всплывающей панели с поиском и выбором заказа; вызов через `/` сохранён.
- Поле ответа занимает одну строку и растёт до семи. Скрепка расположена внутри поля, выбранный файл показан отдельной компактной меткой. Добавлены перетаскивание файла и вставка изображения; ограничение 10 МБ сохранено.
- Заметка, состояние ответа, создание задачи и отправка собраны в одну строку. При недостатке ширины второстепенные подписи заменяются иконками с подсказками. Режим внутренней заметки выделяет редактор жёлтым.
- Убрана постоянная строка подсказок; пояснения доступны у скрепки и отправки. При росте редактора переписка остаётся внизу, если менеджер до этого находился в конце.
- Верхняя карточка клиента сжата до ссылки на полный профиль, задачи перенесены после заказов. Названия языков в настройках показаны словами.
- В «Новом диалоге» запоминается последняя страна пользователя; при вводе номера с `+` поле страны скрывается.

## Границы этой подготовки

Этап 3 **не завершён**. Серверная языковая логика не изменена: черновик пока имеет прежнюю одну языковую версию, редактор AI пока находится внутри панели. Не реализованы две версии черновика/обучающего примера, личный язык менеджера, автоматический выбор языка клиента, выбор языка одной отправки и возврат текста в редактор при ошибке синхронного перевода. Полное уплотнение редактируемых полей правой панели также остаётся в работе.

Не выполнены остальные проверки имени в AI и точного телефона 1С, переработка уведомлений, сворачивание левого меню и полная приёмка ТЗ.

## Проверки и препятствие

Сборка TypeScript/Vite и ESLint проходят. `git diff --check` проходит. Серверный код на этом шаге не менялся.

Браузерный сценарий дополнен проверками строки AI, высоты поля ответа, доли переписки, открытия Alt+A без сжатия ленты и роста редактора. Сценарий **не запускался успешно**, скриншотов и измерений новой версии нет.

После явного подтверждения пользователя предпринята одна попытка открыть тестовую страницу `https://erp.korean.parts/erp-dialogs-step2-frame.html`. Автоматическая проверка разрешений повторно запретила доступ к origin, указав, что подтверждение проверки страницы не разрешает обход предыдущего ограничения. Браузерная работа остановлена; другой браузер, сетевой маршрут или непрямое выполнение для обхода не применялись.

В `main` и рабочий интерфейс изменения не выпущены. Серверная демонстрационная страница пока содержит промежуточную сборку этапа 2 и не подтверждает состояние этого PR. Для завершения визуальной приёмки требуется доступная разрешённая браузерная проверка актуальной сборки.

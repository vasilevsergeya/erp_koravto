# Диалоги: отчёт по шагу 1 — 16.11.2026

Ошибки 1 и 2 раздела 9 исправлены и развёрнуты. Код: `192d2e1`.
Источник требований — `docs/TZ_dialogs_ui.md`, точная копия приложенного ТЗ.
Компоновка и остальные ошибки не входят в этот выпуск.

## Причины

- Сессия была фиксированной, на 8 часов, без refresh и общей обработки 401.
  Подтверждённый эпизод в журнале: вход 09:02 МСК, отказы 17:02 МСК.
  Истечение через 2–3 минуты после свежего входа не воспроизведено.
- Монитор считал `failed` ожидающими событиями. Один видеоролик от
  16.11.2026 11:37:27 МСК превышал лимит 10 МБ и завершился после 10 попыток.
  Событие сохранено без повторной постановки в очередь, причина уточнена
  с общего `ValueError` до подтверждённого `attachment_too_large`.

## Изменения

- `backend/app/api/auth.py`: refresh только действующей сессии, проверки CSRF,
  повторная проверка под блокировкой, короткая сессия смены пароля не продлевается.
- `frontend/src/api.ts`, `main.tsx`: общий refresh, однократный повтор 401,
  общий экран входа, обновление при активности, восстановление WebSocket.
  Ответы старой сессии не могут повторить запрос после смены пользователя.
- `frontend/src/Inbox.tsx`, `inbox-drafts.ts`: сохранение текста, диалога,
  цитаты и идентификатора отправки; разделение черновиков по пользователю и диалогу.
  Файл переживает повторный вход в той же вкладке, но не полную перезагрузку.
- `backend/app/services/webhook_queue.py`, `integration_monitor.py`,
  `workers/worker.py`, `api/integration_health.py`: отдельный учёт ожидающих
  и окончательно ошибочных событий, безопасные причины, список только для администратора.
- `frontend/src/IntegrationQueue.tsx`: Настройки → Ошибки входящих событий.

API Wazzup, схема отправки провайдеру и схема БД не изменены. Миграции нет.
Тестовых сообщений реальным клиентам не отправляли.

## Проверки

- 113 серверных тестов: OK, отдельные PostgreSQL/Redis, внутренняя Docker-сеть без внешнего доступа.
- 10 клиентских тестов: `node --test tests/session.test.mjs`, OK.
- `npm run build`, `npm run lint`, `ruff check app tests`: OK.
- В браузере текст и тот же диалог восстановились после перезагрузки;
  проверочный текст удалён без отправки.
- Наблюдение 16.11.2026, 19:02–19:32 МСК: Выполнен: за 30 минут на обновлённой версии плашки «Войдите в систему» и переход на вход не появились.
- Ожидающая очередь: 0; окончательных ошибок: 1. Фоновый монитор без предупреждения backlog.

Первый полный прогон с уменьшенным лимитом памяти получил тайм-аут прежнего теста
параллельной работы с 1С; штатный лимит позволил пройти всем 113 тестам.
Повторная сборка web на рабочем сервере вызвала временные ошибки запросов и была
остановлена. Доступность восстановлена. Выпущена локальная сборка с проверкой SHA-256.

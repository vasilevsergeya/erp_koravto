# Подтверждение клиента по полному телефону

Автоматическое сопоставление использует только подтверждённое поле `matched_phone` из ответа 1С, равное номеру диалога после проверки E.164. Имя и совпадение части номера не подтверждают привязку. Неподтверждённые результаты показываются как кандидаты отдельно и не добавляют имя или заказы в контекст AI.

Сервис запрашивается с `match=exact`. Изменения расширения подготовлены отдельно: [koravto-1c PR #3](https://github.com/vasilevsergeya/koravto-1c/pull/3). Модули расширения в рабочей базе 1С пока не обновлены. Пока старый сервис не возвращает `matched_phone`, его результаты будут только кандидатами.

Страна номера выводится по телефонному коду, страна контрагента — отдельным полем из 1С. Телефонный код не считается подтверждением места проживания. Даже два точных совпадения с разными контрагентами не выбирают одно имя автоматически.

Приёмка интеграции после обновления расширения: номера с одинаковыми последними шестью цифрами и разными кодами стран должны возвращать разные контрагенты и заказы; повторные строки контактов одного контрагента не должны дублировать результат; отсутствие совпадения даёт пустой список. Старые запросы 1С без `match=exact` сохраняют прежнее поведение.
